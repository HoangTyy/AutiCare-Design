# AutiCare Design (Professional Edition)

**AutiCare** is a specialized platform for autism screening and management, serving teachers, parents, and early intervention specialists. Currently in a design-first development phase, it features a unique "Funtopia" aesthetic that balances supportive playfulness with professional-grade architecture.

---

## 🎨 Design Philosophy
- **Dynamic & Reactive Theming**: Fully integrated with the **Design Lab** for real-time customization.
- **Signature Aesthetics**: Midnight Indigo shell with a clean "Floating Island" workspace layout.
- **Micro-interactions**: High-tech Cyber Blue neon highlights and smooth breathing pulse animations for search results.
- **Empathy-driven UX**: Warm color palettes and context-aware guidance systems.

## 🚀 Key Modules

### 1. Landing Page
- **Neon Branding**: Multi-layered glowing logo and glassmorphism mission panels.
- **Interactive Layout**: 3-column grid navigation with centered branding.
- **Premium Components**: TiltButton CTA pair and scroll-responsive sticky headers.

### 2. Admin Dashboard
- **Workspace Architecture**: Modular "Floating Island" design where data rows act as individual floating cards.
- **Contextual UI**: Modals, breadcrumbs, and confirmation messages that adapt dynamically based on the active administrative tab.
- **Smart Search**: Hierarchical search logic for categories that preserves parent-child relationships.

### 3. Smart Design Lab
- **Real-time Theming**: Granular control over all CSS variables (Primary, Secondary, Accent, Backgrounds).
- **Intelligent Accessibility**: Automatic text contrast calculation based on selected theme colors.

### 4. Design Code Documentation
- **Living Reference**: Interactive pages cataloging all design tokens, components, and animations.
- **Bilingual Support**: Full Vietnamese and English integration across all views and documentation.

## 🛠 Technology Stack
- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Typography**: 
  - `Titan One` (Branding)
  - `Fredoka` (Playful UI)
  - `Be Vietnam Pro` (Primary Content)
- **Styling**: Vanilla CSS with modern variable architecture.

## 🏁 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+)
- [npm](https://www.npmjs.com/)

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
